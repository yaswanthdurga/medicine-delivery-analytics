# Medicine Delivery & Tracking Analytics System

A Python and SQL-based analytics project designed to analyze medicine delivery operations, order performance, revenue, and delivery efficiency.

## Project Overview

The system simulates a medicine delivery platform where customer orders are stored and analyzed to generate operational insights.

The project combines:

- Python
- SQL
- Pandas
- SQLite
- Flask
- Data Analysis
- Git/GitHub

## Key Features

- Medicine order data management
- Delivery status tracking
- Order and revenue analysis
- Delivery performance analysis
- Delayed and cancelled order analysis
- Delivery success rate calculation
- Average delivery time analysis
- Medicine-wise sales analysis
- SQL-based business queries
- Python/Pandas analytics
- Flask API endpoint
